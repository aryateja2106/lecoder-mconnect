## 1. Run the cleanup script

The Cowork sandbox can't `rm` files in this repo (macOS protection on the mounted folder), so the assistant generated a script you run yourself.

```bash
# Optional dry-run first to see what it would do:
chmod +x scripts/cleanup.sh
./scripts/cleanup.sh --dry-run

# Then for real:
./scripts/cleanup.sh
```

The script clears the stale `.git/index.lock`, removes `lecocer-mconnect-test1/`, archives the heavy planning docs, and rips out the Opik observability code. Pass `--skip-opik` if you want to keep it for now.

## 5. Test on a real phone

Open `http://<your-laptop>:3000/m` from your iPhone (you can use `mconnect` or a tunnel). Things to check:

- Header chips render below the notch / Dynamic Island.
- Pinch-zoom in the terminal scales the font.
- Long-press selects text and the iOS context menu shows Copy / Paste.
- Tapping a modifier key arms it (light blue); double-tap locks (deeper blue); next character honours the modifier.
- Long-pressing an arrow auto-repeats at ~60ms.
- Soft keyboard pushes the toolbar up smoothly via `visualViewport`.
