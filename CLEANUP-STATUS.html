Rewrite architecture — proposed

Repo strategy
Keep lecoder-mconnect monorepo. New iOS-native SSH-client target lives at packages/ios-app/; reuse the project, swap the inside. Server (packages/cli) and shared protocol (packages/shared) stay — they're the agent control plane.
Terminal renderer
SwiftTerm (Miguel de Icaza). Already a known quantity in the codebase per the Forge feedback. Drop the WKWebView/xterm.js path entirely — that's the smoothness problem.
SSH transport
Citadel (SwiftNIO, modern, async/await). Falls back to NMSSH only if Citadel can't parse a specific key format you need at the hackathon.
Host onboarding
QR-code handoff from lecoder.lesearch.ai. Drop key + IP into the web form, scan with the app, connection saved. Removes the "copy .pem to phone" friction Forge correctly flagged.
Custom keyboard
System keyboard extension. App Group shared with main app for snippet sync. Esc / Tab / Ctrl / arrows / modifier combo bar + snippet ribbon. Works inside Termius, Blink, RVNC, anywhere.
Agent bootstrap (Context Beam)
One-tap action on a connected SSH session: runs curl -fsSL .../lemem-install.sh | bash to install harness, then openfuse sync <laptop-id> to P2P-sync memories/hooks/rules from your always-on Mac. Phone is just the trigger, not the transport.
Voice layer
SpeechAnalyzer (iOS 18+) → command transcription → agent over the same SSH session. Live Activity on lock screen shows in-flight command + last 5 lines of output. Apple Watch already wired via WatchRelayService.
Distribution
TestFlight beta already live. Watch target piggybacks on the existing App Store record (bundle ID com.lecoder.mconnect). No new provisioning dance.
